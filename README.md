# **kleinanzeigen-discordbot**
### *Noob made Python-Bot, which scrapes offers of Kleinanzeigen.de and notifies you through Discord.*
-------
To use it, go to Kleinanzeigen.de and just search what you are interested in, including the filters like apartment size, price range and so on.
When done just copy the link from your browser and use the "/editlink" command in Discord with the appropiate links.

main file is "bot.py".

>It uses a Text file to save the search-links and the filters (will ignore offer if any assigned filter matches in title).

------------------------------------------------
Commands:

      /viewlink = Shows currently used Links

      /viewfilter = Shows currently used filters

      /editlink = Edit links

      /editfilter = Edit filters
------------------



Free to use for anything.
